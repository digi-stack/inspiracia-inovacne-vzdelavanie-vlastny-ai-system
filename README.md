# Inovačné vzdelávanie - AI v praxi · Inšpirácia

Interaktívna HTML prezentácia inovačného vzdelávania **„AI v praxi - tvorba vlastného AI systému"** pre slovenských učiteľov.

**Nástroje:** Google Gemini, NotebookLM, Gems, Google Drive

**Filozofia:** Vlastný problém, vlastné riešenie - každý účastník odchádza s funkčným AI asistentom pre svoju prax.

**Formát:** 5 hodín online (ZOOM), 35 % teória + 65 % prax, 3 sekcie + záverečná prezentácia

**Termíny:**
- 18.5.2026 - hlavné vzdelávanie (13:00 - 18:00)
- 10.6.2026 - záverečná prezentácia (20:00 - 21:00)

**Lektor:** Ing. Michal Marko, Digi Compliance

**Klient:** Inšpirácia.live

---

## Súbory

- `index.html` - hlavná prezentácia (47 slidov, self-contained, offline-capable)
- `tahak.html` - 1-stranový A4 ťahák pre účastníkov (print-ready)
- `assets/` - logo a obrázky

## Ovládanie prezentácie

- **Šípky ←→** - navigácia medzi slidmi
- **Číslo + Enter** - skok na konkrétny slide (napr. „20" + Enter)
- **O** - otvoriť speaker notes okno
- **N** - prepnúť speaker notes overlay
- **Home / End** - prvý / posledný slide

## Speaker notes v druhom okne

Pre druhý monitor otvor:
```
?role=notes
```
Druhé okno sa synchronizuje cez BroadcastChannel.
